# Cassiopeia Dart protocol

`cassiopeia_protocol` provides the typed session values, judgement events and
session ports shared by game rules, presentation adapters and hosts. It is a
dependency-free Dart library for Flutter, the command line and other Dart hosts.

Import `package:cassiopeia_protocol/cassiopeia_protocol.dart` for these contracts.
The `cassiopeia_runtime` package supplies the Rust C ABI adapter through its
`native.dart` entry.
